# U TECH LOGIC Website

Bilingual, mobile-friendly website for U TECH LOGIC.

## Publish with GitHub Pages
1. Open the repository **Settings** tab.
2. Choose **Pages** from the left menu.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. After publishing, the website should be available at https://u-2005-jpg.github.io/U-TECH-LOGIC-/
